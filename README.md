# Aplikasi kasir untuk penjualan di toko 

Aplikasi ini adalah sistem backend berbasis web untuk mengelola stok barang dan transaksi penjualan. Proyek ini dibuat untuk memudahkan bisnis saya sendiri sekaligus sebagai sarana hobi mengembangkan aplikasi yang solutif.

## 🚀 Fitur Utama
- **Manajemen Data:** Tambah, edit, dan hapus data (CRUD) dengan validasi aman.
- **Autentikasi:** Sistem login multi-level (Admin dan Kasir) menggunakan enkripsi password.
- **Laporan Otomatis:** Ekspor riwayat transaksi bulanan ke dalam format PDF/Excel.

## 🛠️ Teknologi yang Digunakan
- **Backend:** PHP (Laravel versi 13 / PHP Native)
- **Database:** MySQL / MariaDB
- **Frontend (Opsional):** Bootstrap / Tailwind CSS
- **Library Tambahan:** FPDF untuk cetak nota

## 💻 Cara Menjalankan Proyek Ini Di Komputer Anda

Jika Anda ingin menguji aplikasi ini secara lokal, ikuti langkah berikut:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com
   ```

2. **Pindahkan folder ke direktori server lokal:**
   - Jika menggunakan XAMPP, taruh di folder `htdocs`.

3. **Import Database:**
   - Buka `phpMyAdmin`, buat database baru bernama `nama_database`.
   - Import file `database.sql` yang ada di dalam proyek ini.

4. **Konfigurasi Koneksi:**
   - Sesuaikan *username* dan *password* database Anda di file konfigurasi (`config.php` atau `.env`).

5. **Akses via Browser:**
   - Buka `http://localhost/nama-folder-proyek`
